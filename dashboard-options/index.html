Dashboard layout options

Three working versions of the dashboard, all with the same sample data. They're temporary: the one that's chosen replaces the current dashboard, and these pages go.

  • A: Sidebar app The programs are listed down the left. The right side shows one program at a time, with its patient list on the page. It opens on an overview.
  • B: One scrolling page No menus. Every program is a full-width band, one after another, each with a patient list that opens in place.
  • C: Follow-up worklist The people first: one list of everyone who needs follow-up, filtered by program, with each program's numbers underneath.

The current dashboard, for comparison.
